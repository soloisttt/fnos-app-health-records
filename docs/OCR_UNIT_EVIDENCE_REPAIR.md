# OCR 单位来源关联修复

表格表头“名”按项目名称列处理；仍须同时存在明确结果列及可识别表头。居中的名称表头允许正文左对齐，以前一组表头的边界隔离相邻栏，保留结果跨列、低置信度及歧义阻断。

历史记录通过现有指标归一化维护流程修复，无需重新调用 AI 或 OCR。仅处理“结果单位无法回指 OCR 证据”的记录：从最新 OCR 重建表格，要求同页、原来源行覆盖、项目名、结果文本、数值、单位均一致且候选唯一。只补本行的单位来源，不继承旁栏单位，不猜测缺失单位。已人工修改或已有单位映射的记录不覆盖。

修复仅补充 evidence_json 的表格来源信息，不改变指标 ID、值、单位、参考范围或人工校对。证据补齐和归一化在同一保存点执行，失败回滚。无可靠匹配的记录继续保留待核对。没有 schema 或版本编号变化。

对现有真实数据操作前保留数据库备份；本次诊断先在数据库副本验证，测试仅使用合成项目和数值，不把真实报告放入测试或日志。
